## About Me

I build practical AI systems that ship in the real world. My senior thesis turned a SoftBank Pepper humanoid into a bilingual hospital receptionist for **Andalusia Hospital Group**, combining Whisper STT, retrieval-augmented generation, agentic tool-calling LLMs, face recognition, and autonomous navigation — all running on a local LAN with no cloud dependency.

Outside the thesis I work across the ML stack: classical models (LightGBM, RandomForest), deep learning (CNNs for medical imaging), NLP (extractive + abstractive summarization, RAG, NER), reinforcement learning, and computer vision. I care about making models actually deployable, not just notebook curiosities.
